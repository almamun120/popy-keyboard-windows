# Popy Keyboard

Bangla phonetic typing for Windows, built on the open-source Avro Keyboard (OmicronLab, MPL-2.0) with the Popy phonetic layout.

Unicode compliant open source Bangla typing software (IME).
Visit: [https://www.omicronlab.com](https://www.omicronlab.com "OmicronLab") for latest version.

## Required Delphi Version

Was tested with **Delphi 12 community edition**

The community edition can be download from here:
https://www.embarcadero.com/products/delphi/starter/free-download

## Popy Keyboard 1.0 (based on Avro Keyboard ExtremeMOD)

Changes: Popy conjuncts now join only for the 163 listed pairs (a single Shift tap forces a join or an independent vowel), Popy dictionary auto-correct + preview suggestions (`PopyWords.txt`), Shift / `o` / `q` roles documented; UniBijoy layout added, redesigned Popy layout viewer (keys + rules pages), top bar gap closed, Right Win as keyboard mode switch key, ANSI-mode o/q markers.

### Installed and portable use (same program files)

The program decides at start-up. If its own folder holds data (`Keyboard Layouts`, `Skin`, `Database.db3`, `Settings.xml` or an empty `portable.txt`) and can be written to, it runs portable: everything stays in that folder and settings go to `Settings.xml`. Otherwise it runs installed: data in `C:\ProgramData\Avro Keyboard`, settings in the registry. Missing data files (database, auto-correct dictionary, layouts, skins, virtual font) are written from a copy stored inside the program; existing files are never overwritten.

## Popy Layout

A rule based phonetic layout (see `docs/PopyLayout.md`). Select it from
**Select keyboard layout → Popy Layout (Phonetic)**. Engine: `Keyboard and Spell checker/Classes/clsPopyPhonetic.pas`
(VCL-free, tested by `tests/PopyTest.pas` against `tests/typing_cases.tsv`).
Only 163 listed consonant pairs join by themselves; a Shift tap (shown as an `s` marker) forces any other join (`k⇧f` = ক্ফ) or an independent vowel (`bo⇧i` = বই); `q` is only for special letters (ঁ ঃ ৎ ৳ ঋ ষ ক্স হ য ঞ).
With *Enable Auto Correct* on, finished words are matched against `PopyWords.txt` (`Classes/clsPopyDictionary.pas`)
and, with the preview window on, suggestions are listed (click to pick). Details, including Shift vs `o` vs `q`: `docs/PopyLayout.md`.

This build has no update check and no web links (website, forum, social, "on the web" menus).

## Release (portable + setup)

1. Build `WholeProject.groupproj` in Release (Delphi 12) - output goes to `build\`.
2. Run `make-release.bat 1.0.0` - it makes `dist\PopyKeyboard-1.0.0-portable.zip` (contains `portable.txt`; unzip anywhere / USB) and
   `dist\setup_popykeyboard_1.0.0.exe` (needs Inno Setup 6, script: `installer\PopyKeyboard.iss`).

Images and icons are generated by `python tools/make_branding.py` and `python tools/make_tray_res.py` (Pillow with raqm).

## Automatic build

`.github/workflows/build.yml` runs the Popy engine tests on GitHub and builds the Delphi projects on a
self-hosted Windows runner that has Delphi installed (labels: `self-hosted, windows, delphi`). Push a `v*` tag for a release zip.

## Building Standard and Portable editions

### Compiler Directives

Open `ProjectDefines.inc` file in the root folder of the source.

For building portable edition, add the following line in this file and compile:

    {$Define PortableOn}

For building standard edition, remove the above line from the
file or make it a comment like the following and then compile:

    {.$Define PortableOn}

or,

    //{$Define PortableOn}

### Building Projects

Delphi community edition doesn't come with command line compiler. In order to build projects:

- Run `build-ce.bat`
- Open `WholeProject.groupproj` in Delphi IDE and run `Build All` from the project group
- Built and renamed files will be under `build` directory
