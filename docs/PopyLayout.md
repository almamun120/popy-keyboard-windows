# পপি লেআউট (Popy Layout) — টাইপিং গাইড

পপি লেআউট Avro Keyboard-এর একটি নতুন, নিয়মভিত্তিক ফোনেটিক লেআউট। ইংরেজি হরফ টাইপ করলে নিচের নিয়মে বাংলা হয়। টাইপ করার সময় একই কী-ক্রমে সবসময় একই বাংলা আসে। অটো কারেকশন চালু থাকলে শব্দ শেষ হওয়ার সময় ডাটাবেসের (অভিধান) সাথে মিলিয়ে বানান ঠিক করা হয় এবং প্রিভিউ চালু থাকলে সাজেশন দেখায় (দেখুন ১০ নম্বর)।

**যুক্তাক্ষর নিয়ম:** দুটি ব্যঞ্জন পাশাপাশি টাইপ করলে শুধু **তালিকাভুক্ত ১৬৩টি** জোড়া নিজে থেকে যুক্ত হয় (৭ নম্বর) — ক, খ-এর মতো `kf` = কফ, `kkh` = কখ। বাকি সব জোড়া আলাদাই থাকে। জোর করে যুক্ত করতে **শিফট** একবার চেপে ছেড়ে দিন (শুধু শিফট, অন্য কিছুর সাথে নয়): `k⇧f` = ক্ফ (`⇧` মানে শিফট ট্যাপ)। অটো কারেকশন চালু থাকুক বা না থাকুক এই নিয়ম একই।

**তিন কী, তিন কাজ (বিস্তারিত ৮ নম্বরে):** **শিফট** = স্বয়ংক্রিয় মিলন বন্ধ করে নিজের মতো বসাও (ব্যঞ্জনের আগে = যুক্ত, স্বরের আগে = স্বাধীন স্বর); **`o`** = ব্যঞ্জনের পরে অ-ধ্বনি, যুক্ত হতে দেয় না; **`q`** = শুধু বিশেষ বর্ণ ও চিহ্ন (ঁ ঃ ৎ ৳ ঋ ষ ক্স হ য ঞ ! ?)।

## চালু করার নিয়ম

ট্রে আইকন বা Top Bar-এর মেনু থেকে **Select keyboard layout → Popy Layout (Phonetic)** বেছে নিন। এরপর বাংলা মোডে (F12, Right Win বা আপনার ঠিক করা কী) টাইপ করুন।

- সব হরফ ছোট হাতের ধরেই টাইপ হয়; Shift বা Caps Lock ফলাফল বদলায় না।
- Space, Enter, Tab, তীরচিহ্ন (সাজেশন থাকলে ↑/↓ সাজেশন বাছে), Home/End ও Delete চাপলে শব্দ শেষ ধরা হয়। (অটো কারেকশন শুধু Space/Enter/Tab-এ হয়; Esc, তীরচিহ্ন, Home/End, Delete-এ শব্দ যেমন টাইপ করেছেন তেমনই থাকে।)
- Backspace চলমান শব্দের শেষ টাইপ করা কী একটি একটি করে মোছে।
- ব্যঞ্জনের পরে `o` বা `q` চাপলে, আর শিফট একা চাপলে, লেখায় কিছু বসে না। তাই একটি ছোট `o` / `q` / `s` অক্ষর (শিফটের জন্য `s`) দেখা যায় (ANSI আউটপুটেও আসল অক্ষরই দেখা যায়)। পরের কী চাপলে বা শব্দ শেষ হলে সেটি মুছে যায়। শিফটের `s` দেখলে বুঝবেন শিফট ধরা পড়েছে; Backspace দিলে সেটি মুছে যায়।
- Ctrl/Alt/Win-এর সাথে চাপা শর্টকাট (যেমন Ctrl+V) শব্দ শেষ করে দেয়।

## ২. ব্যঞ্জন

| টাইপ | অক্ষর | টাইপ | অক্ষর | টাইপ | অক্ষর |
|---|---|---|---|---|---|
| `k` | ক | `kh` | খ | `g` | গ |
| `gh` | ঘ | `nng` | ঙ | `c` | চ |
| `ch` | ছ | `j` | জ | `jh` | ঝ |
| `nnn` | ঞ | `tt` | ট | `tth` | ঠ |
| `dd` | ড | `ddh` | ঢ | `nn` | ণ |
| `t` | ত | `th` | থ | `d` | দ |
| `dh` | ধ | `n` | ন | `p` | প |
| `f / ph` | ফ | `b` | ব (শুধু স্বাধীন) | `bh / v` | ভ |
| `m` | ম | `y` | য় | `z` | য |
| `r` | র | `l` | ল | `s` | স |
| `ss` | শ | `sss` | ষ | `h` | হ |
| `x` | ক্ষ | `rr` | ড় | `rrh` | ঢ় |

- `r` = র, `rr` = ড়, `rrh` = ঢ়, `rrr` = ঋ/ৃ। তাই ড়ি/ড়ী সরাসরি লেখা যায়: বাড়ি = `barri`, ঘড়ি = `ghorri`, ঝড়ী = `jhorrii`। ঋ/ৃ: ঋষি = `rrrsssi`, কৃত = `krrrt`।
- `b` সবসময় আলাদা (স্বাধীন) ব দেয়, আগের অক্ষরের সাথে যুক্ত হয় না: `kb` = কব। যুক্ত ব (ব-ফলা) লিখতে `w` ব্যবহার করুন।
- `w` ব্যঞ্জনের পরে **ব-ফলা** (`sw` = স্ব, `dw` = দ্ব); শব্দের শুরুতে বা স্বরের পরে **ও** (`wjon` = ওজন)।
- ন্ন লিখতে শিফট লাগে: `n⇧n` = ন্ন, `bhin⇧no` = ভিন্ন। (`nn` = ণ, তাই ন + ন সরাসরি লেখা যায় না।)
- দুটি ব্যঞ্জন পাশাপাশি লিখলে সবসময় যুক্ত হয় না — কোন জোড়া নিজে যুক্ত হয় তা ৭ নম্বরে। বাকিগুলো শিফট (`⇧`) দিয়ে যুক্ত করুন।

## ৪. `q` এর নিয়ম

`q` শুধু **বিশেষ বর্ণ ও চিহ্ন** আনার চাবি। যুক্ত করা আর স্বাধীন স্বর আনা `q`-এর কাজ নয়, সেটা শিফটের (৮ নম্বর)।

| টাইপ | ফল | উদাহরণ |
|---|---|---|
| `qq` | ঁ | `caqqd` = চাঁদ |
| `qw` | ঃ | `duqwkh` = দুঃখ |
| `qt` | ৎ (ব্যঞ্জনের পরেও) | `jogqt` = জগৎ, `hotthaqt` = হঠাৎ |
| `qk` | ৳ | |
| `q.` / `q,` | ? / ! | |
| `qr` | ঋ (শুরুতে বা স্বরের পরে); ব্যঞ্জনের পরে ঋ-কার | `qr` = ঋ, `kqr` = কৃ |
| `qs` | **স্বাধীন** ষ (জোড়া লাগে না) | `kqs` = কষ (`ksss` = ক্ষ) |
| `qx` | ক্স | |
| `qh` | **স্বাধীন** হ | `kqh` = কহ |
| `qz` | **স্বাধীন** য | `kqz` = কয, `oqzotha` = অযথা |
| `qn` | ঞ (আগের মতোই; ব্যঞ্জনের পরে যুক্ত হয়) | `jqno` = জ্ঞ, `ponnnco` = পঞ্চ |

- `rrr` = `qr`, `sss` = ষ (যুক্ত হয়) বনাম `qs` = স্বাধীন ষ, `nnn` = `qn` = ঞ — আগের মতোই। `y` = য় স্বাধীন বর্ণ।
- **অন্য কোনো অক্ষরের আগে `q` কিছুই করে না**: `qjo` = জ। শুধু `q`-এর দুই পাশের অক্ষর মিশতে পারে না (তাই `tqt` = তত, ট নয়)। যুক্ত করার জন্য `q` ব্যবহার করবেন না, সেটা শিফটের কাজ।
- পুরনো অভ্যাসের `boqi` = বই বা `koqoo` = কও এখনো সেই ফলই দেয়, কিন্তু নিয়ম হিসেবে শিফট (`bo⇧i`, `ko⇧oo`) ব্যবহার করুন।
- `rqz` = র‍্য (নিচের ৫ নম্বর দেখুন)।

## ৫. র-ফলা, রেফ, য-ফলা, ব-ফলা

- **র-ফলা**: ব্যঞ্জনের পরে সরাসরি `r`: `pr` = প্র, `kr` = ক্র, `str` = স্ত্র, `prem` = প্রেম।
- **রেফ**: শুরুতে বা স্বরের পরে `r` + ব্যঞ্জন নিজে থেকেই: `durga` = দুর্গা, `orth` = অর্থ। ব্যঞ্জনের পরে: `dhorm` = ধর্ম (`o` দিয়ে র আলাদা করে)।
- **য-ফলা**: ব্যঞ্জনের পরে `z`: `kz` = ক্য, `bidza` = বিদ্যা, `sotz` = সত্য। `zz` = য্য।
- **র‍্য (র-এর সাথে য-ফলা)**: শব্দের শুরুতে `rz` → র‍্যাব = `rzab`। অন্য জায়গায় `rqz`। রেফ + য লিখতে সাধারণ `rz`: কার্য = `karz`, সূর্য = `suurz`।
- **স্বরবর্ণে য-ফলা**: অ-এর (বা যেকোনো স্বরবর্ণের) পরে `z` = য-ফলা: অ্যাপ = `ozap`। য-ফলা না চাইলে `qz` (স্বাধীন য) লিখুন: অযথা = `oqzotha`।
- **ব-ফলা**: ব্যঞ্জনের পরে `w`: `sw` = স্ব, `dw` = দ্ব। অন্যত্র `w` = ও।

## ৭. যুক্তবর্ণ — কোনগুলো নিজে যুক্ত হয়, বাকিগুলো কীভাবে

### নিয়ম

1. **তালিকাভুক্ত ১৬৩টি জোড়া** নিজে থেকে যুক্ত হয় (নিচের তালিকা: ডিকশনারির `conjunct_list_v2`-এর ১ নং ১৪৬টি + ২ নং ১৭টি)।
2. **রেফ** (`r` + যেকোনো ব্যঞ্জন, আগে স্বর/শব্দের শুরু) আগের মতোই যুক্ত হয়: `durga` = দুর্গা, `orth` = অর্থ।
3. **তালিকার বাইরের** যেকোনো জোড়া আলাদা থাকে: `kf` = কফ, `kbh` = কভ, `khs` = খস, `nk` = নক, `jogt` = জগত।
4. জোর করে যুক্ত করতে: **শিফট ট্যাপ** (`⇧`): `k⇧f` = ক্ফ। বিস্তারিত ৮ নম্বরে।
5. এটি অটো কারেকশন **চালু বা বন্ধ — দুই অবস্থাতেই** একই।
6. **র-ফলা ও য-ফলার পর** আর কোনো ব্যঞ্জন নিজে যুক্ত হয় না (শুধু কার/স্বর বসে): `prt` = প্রত, `prk` = প্রক, `dhrm` = ধ্রম, `kzt` = ক্যত। (য-ফলা র-ফলার পরে বসতে পারে: `brzan` = ব্র্যান।) যুক্ত করতে চাইলে শিফট: `pr⇧k` = প্র্ক।
7. **য় (`y`) স্বাধীন বর্ণ**: সে নিজে ফলা হয় না, কিন্তু তার সাথে য-ফলা (`z`) যুক্ত হতে পারে: `yz` = য়্য, `poyz` = পয়্য। `k⇧y` লিখলেও য় ফলা হয় না (= কয়)।
8. `b` ও `y` কখনো নিজে যুক্ত হয় না (ব-ফলা = `w`, য়-কে শিফট দিয়েও যুক্ত করা যায় না, শুধু `b` যুক্ত হয়: `k⇧b` = ক্ব)।

## ৮. শিফট, `o` ও `q` — ব্যবহার এবং পার্থক্য

**মূল কথা:** পপি লেআউট আগে "লোভী" (গ্রিডি) পদ্ধতিতে কাজ করে — সবচেয়ে লম্বা কী-ক্রম আগে মেলে (`tt` = ট, `nn` = ণ, `kh` = খ …) এবং ১৬৩টি জোড়া নিজে যুক্ত হয়। এটা আগের মতোই থাকে। **যেখানে এই স্বয়ংক্রিয় নিয়ম আপনার চাওয়া দেয় না, শুধু সেখানেই** এই তিন কী লাগে:

| কী | কাজ |
|---|---|
| **শিফট** (একা চেপে ছাড়া) | পরের কী-র সাথে স্বয়ংক্রিয় মিলন বন্ধ করে, নিজের মতো বসায়: **ব্যঞ্জনের আগে = জোর করে যুক্ত**, **স্বরের আগে = স্বাধীন স্বর**। |
| `o` | ব্যঞ্জনের পরে **অ-ধ্বনি**: নিজে কিছু লেখে না, কিন্তু জোড়াটিকে **যুক্ত হতে দেয় না**। শব্দের শুরুতে/স্বরের পরে = অ। |
| `q` | শুধু **বিশেষ বর্ণ ও চিহ্ন**: ঁ ঃ ৎ ৳ ঋ/ৃ ষ ক্স হ য ঞ ! ? (৪ নম্বর)। |

### গ্রিডি মোড চালু/বন্ধ (Windows)

মেনুতে (ট্রে/টপবারের মেনু, "Enable Auto Correct"-এর ঠিক নিচে) **"Popy: Greedy mode (auto-join listed conjuncts)"** আছে (ডিফল্টে চালু, শুধু পপি লেআউটে সক্রিয়)।

- **চালু:** ১৬৩টি তালিকাভুক্ত জোড়া নিজে যুক্ত হয় (`kt` = ক্ত); বাকিগুলো শিফট দিয়ে।
- **বন্ধ (নন-গ্রিডি):** **কিছুই নিজে যুক্ত হয় না।** শিফট এখানে **পোস্টফিক্স**: যে ব্যঞ্জনটি এইমাত্র লিখেছেন, শিফট চাপলে সেটি **আগের ব্যঞ্জনের সাথে যুক্ত** হয়ে যায়। (গ্রিডি চালুতে শিফট আগের মতো প্রিফিক্স — ব্যঞ্জনের **আগে** চাপতে হয়।)

  | টাইপ | ফল |
  |---|---|
  | `km⇧` | ক্ম |
  | `kt⇧` | ক্ত |
  | `bj⇧r⇧` | ব্জ্র (প্রতিটি জোড়ার পরে একবার করে শিফট) |
  | `bjr⇧` | বজ্র (শিফট শুধু শেষ জোড়া যুক্ত করে) |
  | `rk⇧` | র্ক (রেফ) |
  | `kr⇧` | ক্র (র-ফলা) |
  | `kz⇧` | ক্য (য-ফলা) |
  | `oz⇧a` | অ্যা |
  | `br⇧z⇧an` | ব্র্যান |
  | `jqn⇧` | জ্ঞ |
  | `kqs⇧` | ক্ষ |
  | `tot⇧` | ত্ত |
  | `dod⇧` | দ্দ |
  | `nonn⇧` | ন্ণ |
  | `ka⇧` | কআ (কার-এর পর শিফট = স্বাধীন স্বর) |
  | `ko⇧` | কঅ |
  | `koo⇧` | কও |
  | `ki⇧` | কই |

  - **`র` ও `য` স্বাধীন বর্ণ:** `rk` = রক, `kr` = কর, `kz` = কয।
  - **`o` এখানে শুধু দ্বিত্বের জন্য:** `tt` একটি টোকেন (= ট), তাই ত্ত লিখতে মাঝে `o` দিয়ে টোকেন ভাগ করুন: `tot⇧`। `o` ব্যঞ্জনের পরে কিছু লেখে না, তবে শেষ কী হলে আগের মতো লাল `o` মার্কার দেখা যায়; `o`-এর পরে শিফট দিলে সেটা স্বাধীন অ হয় (`ko⇧` = কঅ)। (`oo`, `oi`, শুরুর অ ইত্যাদি স্বর-হিসেবে `o` আগের মতো।)
  - শিফট ব্যঞ্জনের পরে না হলে (শুরুতে, স্বরের পরে) কিছু করে না। একবার যুক্ত হওয়ার পর আবার শিফট দিলেও দ্বিতীয়বার যুক্ত হয় না।
  - `qn`, `qs` স্বাধীন ঞ, ষ: `qn⇧` / `qs⇧` দিয়ে যুক্ত। `qz` আলাদা লাগে না। `qq qw qt qk q. q, qr qx qh` আগের মতোই।
- `qn` গ্রিডি চালুতেও এখন তালিকা মানে: শুধু তালিকাভুক্ত জোড়ায় নিজে যুক্ত হয় (জ্ঞ = `jqn`); অন্যত্র স্বাধীন (`kqn` = কঞ), জোর করতে `k⇧qn` = ক্ঞ।

### শিফট কীভাবে কাজ করে

- **শুধু শিফট চাপলেই** (চেপে ছেড়ে দিলে, মাঝে অন্য কী না চেপে) কাজ হয়। Shift+অক্ষর, Ctrl+Shift, Alt+Shift কিছু করে না। বাম ও ডান দুই শিফটই চলে।
- ট্যাপ ধরা পড়লে শব্দের শেষে একটি ছোট **`s`** দেখা যায় (প্রিভিউয়ের ইংরেজি লাইনে `⇧`)। পরের কী-তে কাজটা হয়ে `s` মুছে যায়।
- **একবারই কাজ করে:** শিফট চেপে ধরে রাখলে (কী রিপিটে) কিংবা বারবার চাপলেও একবারের সমান।
- **Backspace** দিলে শিফটের ঘটনাটা (`s`) মুছে যায়।
- শিফটের পরে ব্যঞ্জনও স্বর কোনোটাই না এলে (Space, চিহ্ন) কিছুই হয় না, `s` মুছে যায়। শব্দের শুরুতে শিফট চাপলে কিছু হয় না।
- Windows-এর Sticky Keys: শিফট পরপর পাঁচবার চাপলে Windows নিজেই একটা ডায়ালগ খোলে। এটা Windows-এর সেটিং।

### `o` — অ, আর যুক্ত না করা

- শব্দের শুরুতে বা স্বরের পরে: অ (`ogni` = অগ্নি)।
- ব্যঞ্জনের পরে: কিছু বসে না। `ko` = ক (একটি `o` অক্ষর কিছুক্ষণ দেখা যায়, পরের কী-তে মুছে যায়)।
- দুই ব্যঞ্জনের মাঝে `o` থাকলে জোড়া **আলাদা** থাকে। এটি তখনই দরকার যখন জোড়াটি তালিকাভুক্ত (নিজে যুক্ত হয়) কিন্তু আপনি যুক্ত চান না:

| চান | টাইপ | `o` ছাড়া |
|---|---|---|
| কতো | `koto` | `kto` = ক্তো |
| বাকস (বাক্স নয়) | `bakos` | `baks` = বাক্স |

- `oo` = ও / ো, `oi` = ঐ / ৈ, `ou` = ঔ / ৌ (দেখুন ১ নম্বর)।

## ১০. ডিকশনারি অটো-কারেকশন ও সাজেশন (শুধু পপি লেআউট)

পপি লেআউটের জন্য বানানো আলাদা ডাটাবেস (`PopyWords.txt`, ৪,৫১,৭৪১টি শব্দ ও তাদের ব্যবহার-সংখ্যা (কোনো শব্দ বাদ দেওয়া হয়নি)) থেকে।

**অটো কারেকশন চালু থাকলে** (Top Bar/ট্রে → **Enable Auto Correct**; লিনাক্সে সেটিংসের "Popy: dictionary auto-correct"):

- Space / Enter / Tab চাপলে শব্দ ডাটাবেসে খোঁজা হয়।
  - ডাটাবেসে হুবহু থাকলে → যেমন আছে তেমনই।
  - না থাকলে, কিন্তু এমন শব্দ থাকে যেটি শুধু এই বর্ণগুলোর পার্থক্যে আলাদা — ই/ঈ, ি/ী, উ/ঊ, ু/ূ, শ/ষ/স, ণ/ন, ৎ/ত — তাহলে ব্যবহার-সংখ্যায় সবচেয়ে বড় শব্দটি বসে (যেমন `tumii` = তুমী → তুমি)।
  - কিছু না মিললে → যা টাইপ করেছেন তাই।
- সংখ্যা, ইংরেজি বা চিহ্নযুক্ত লেখা (সংখ্যা, URL, ইংরেজি) কখনো বদলায় না।

**প্রিভিউ চালু থাকলে** (**Show preview window**):

- প্রিভিউয়ের উপরে আপনার টাইপ করা ইংরেজি হরফ দেখায়।
- অটো কারেকশন চালু থাকলে তার নিচে তালিকা: প্রথমে আপনি যা টাইপ করেছেন, তারপর ডাটাবেসের সাজেশন (একই শব্দের বিকল্প বানান, তারপর ওই বর্ণ দিয়ে শুরু হওয়া শব্দ, বেশি ব্যবহৃত আগে, সর্বোচ্চ ৮টি)।
- মাউস দিয়ে ক্লিক করলে শব্দটি বদলে যায়। কীবোর্ডে (Windows ও Linux দুটোতেই): **↓** চেপে তালিকায় নামুন, **↑** দিয়ে উঠুন, পছন্দেরটায় থেমে **Space / Enter / Tab** চাপুন — বাছা শব্দ বসে (Space দিলে শব্দের পরে স্পেসও পড়ে)।
- অটো কারেকশন বন্ধ থাকলে তালিকা থাকে না, শুধু ইংরেজি হরফ দেখায়।

**অটো কারেকশন ঠেকাতে চাইলে:** প্রিভিউ তালিকার প্রথম আইটেম (আপনার টাইপ করা শব্দ) বাছুন, অথবা Esc / ← / → / Home / End / Delete দিয়ে শব্দ শেষ করুন (Windows)। লিনাক্সে ↓ চেপে প্রথম আইটেমে গিয়ে Space দিন। (Windows-এ ↓ দিলে এখন সাজেশন বাছা হয়, তাই ↑/↓ দিয়ে শব্দ শেষ করা যায় না।) বা অটো কারেকশন বন্ধ রাখুন।

**মনে রাখবেন:**

- ডাটাবেসে শব্দ না থাকা মানে শব্দটি ভুল নয়। নাম, বিদেশি শব্দ, নতুন শব্দে অটো কারেকশন তাই কিছু করে না (কিংবা কাছাকাছি কোনো শব্দ বসাতে পারে — দরকার হলে ওপরের পদ্ধতিতে ঠেকান)।
- অটো কারেকশন শুধু উপরের বর্ণগুলোর পার্থক্য মেলায়; যুক্তাক্ষরের নিয়ম (৭) এতে বদলায় না। অটো কারেকশন বন্ধ থাকলেও যুক্তাক্ষরের নিয়ম একই।
- ডাটাবেসের ফাইল (`PopyWords.txt` / লিনাক্সে `popy_words.txt.gz`) না থাকলে অটো কারেকশন ও সাজেশন কিছু করে না। Windows-এ ফাইলটি ডেটা ফোল্ডারে (`Avro Keyboard` ফোল্ডার, পোর্টেবলে প্রোগ্রামের ফোল্ডার) বসে; নিজের শব্দ-তালিকা দিতে ওই ফাইলে `শব্দ<TAB>সংখ্যা` লাইন যোগ করুন।
